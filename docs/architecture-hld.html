System overview

Guarantees the design enforces

Agents never write tablesEvery agent write goes through an RPC function that checks the device, user and clock state. The service-role key never leaves Supabase.
No capture on a missA missed check-in sends an event with idle time and device state only. Nothing is uploaded.
Every capture view is auditedA signed URL is issued only after the access check and the audit-log entry, and it expires within 5 minutes.
Timesheets are derivedSegments are rebuilt deterministically from raw events. Flagged time is highlighted, never deducted.
Works offlineEvents and captures queue encrypted on the device for up to 7 days. Each event has a client UUID, so replays are safe.
One region in the pilotEverything runs in US East. An EU project is added when the first EU customer signs.
